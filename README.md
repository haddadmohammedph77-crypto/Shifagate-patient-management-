# Shifagate — International Patient Management Platform

Shifagate is a bilingual (Arabic/English) platform concept for helping international patients access medical services in India and helping staff coordinate each patient's journey.

## Planned applications

- **Patient app (Android and iOS):** registration, treatment requests, medical document submission, appointment updates, travel-support requests, and case-status tracking.
- **Staff dashboard (web):** patient case management, hospital and doctor coordination, appointments, estimates, invoices, and task tracking.

## Planned technology

- React Native + Expo for the mobile application
- Supabase for authentication and application data
- A web dashboard for staff and administrators
- GitHub for source-code version control

## Development status

This repository contains the initial product plan. The application has not yet been implemented.

## Important privacy and security notice

Do not commit real patient information, passport details, medical reports, credentials, API keys, or private contact information to this repository. Use fictional test data during development. Patient records must be stored in a properly secured database with role-based access and appropriate consent. Before launch, review applicable privacy, healthcare, and data-protection requirements.
