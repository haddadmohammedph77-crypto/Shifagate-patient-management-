# Shifagate mobile app

This is the first UI prototype for the Shifagate patient app, built with React Native and Expo.

## Preview

1. Open this project in Expo Snack (https://snack.expo.dev/) or clone the repository into a development environment.
2. Copy the contents of `App.js` into the Snack editor.
3. Select the iOS or Android preview.
4. Use the language button to switch between Arabic and English.

This prototype uses sample interface content only. Buttons currently show a preview notice; authentication, patient records, uploads, messaging, and service requests are not connected yet.

## Privacy

Do not enter real patient data into this prototype. Secure authentication, storage, access controls, consent, and legal review are required before any pilot with real patients.
